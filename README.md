# LE TEXT PAGE

Vercel-ready static + localStorage demo of a text publishing site.

## Features

- Index → OPEN PAGE / START TEXT
- Start → Login / Register card switch
- Main (guest) → public list, search, cannot create
- Dashboard (logged-in) → full + menu
- Create with multiple file attachments
- Pages, Settings, View + comments/replies/likes

## Demo storage

localStorage keys: le_text_users, le_text_user, le_text_pages, le_text_comments

## Production

Next.js + Supabase + Vercel Blob recommended. See original README for schema.
